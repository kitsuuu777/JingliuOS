# JingliuOS

Personal NixOS flake config for a laptop running Hyprland, with a Honkai: Star Rail (Jingliu) themed desktop and a gaming-focused setup.

## What's inside

- **Window manager:** [Hyprland](https://hyprland.org/) (via UWSM), configured through [`hyprland.lua`](https://github.com/hyprland-community) bindings
- **Shell / bar:** [Noctalia](https://github.com/noctalia-dev/noctalia-shell) (controlled via IPC from startup/gaming scripts)
- **Theme:** Custom Jingliu color scheme (see `dotfiles/hypr/config/colors.json`, `dotfiles/noctalia/colorschemes/Jingliu`) + Catppuccin Mocha Sky cursors
- **Splash screen:** Custom QML splash (`jingliu-splash`) shown on login until the desktop is fully ready
- **Gaming:** Steam, Heroic, gamescope/gamemode/mangohud, plus a background watcher that auto-switches power profile and disables Hyprland effects while a game is running on the `gaming` workspace
- **Login manager:** greetd + tuigreet
- **Shell:** fish, themed kitty terminal

## Requirements

- A UEFI machine (this config uses `systemd-boot`)
- NixOS installed with flakes enabled
- The hardware config in `hosts/laptop/hardware-configuration.nix` matches **my** laptop (disk UUIDs, AMD CPU + NVIDIA GPU, `mt7921e` wifi). Using this on different hardware, generate your own with `nixos-generate-config` and swap that file first.

Pulled in by `flake.nix`:

| Input | Purpose |

## Installation

> ⚠️ This is a personal config tailored to my hardware and preferences. Read through `hosts/laptop/` and `modules/` before applying it anywhere.

1. Boot a NixOS installer with flakes enabled.
2. Partition/format your disks and mount them under `/mnt` as usual.
3. Generate your own hardware config and replace the existing one:
   ```bash
   nixos-generate-config --root /mnt
   cp /mnt/etc/nixos/hardware-configuration.nix hosts/laptop/hardware-configuration.nix
   ```
4. Adjust `hosts/laptop/configuration.nix` (hostname, etc.) and `home/kitsu/` (username, git identity) to your own setup.
5. Install:
   ```bash
   sudo nixos-install --root /mnt --flake .#jingliuOS
   ```
6. Reboot.

## Notable custom behavior

- **`jingliu-startup`** runs automatically on Hyprland launch (wired via `dotfiles/hypr/config/autostart.lua`). It shows the splash screen, hides the Noctalia bar until ready, launches the autostart apps (Firefox, Vesktop, Pear/YouTube Music, Heroic, Dolphin, an HSR dashboard in kitty), and waits (up to 60s) for all of them to have a window open before tearing down the splash. Logs to `/tmp/jingliu-startup.log`.
- **`gaming-watcher`** runs as a `systemd --user` service. It polls Hyprland every 2s for a client on the `gaming` workspace; when found, it switches to the `performance` power profile, disables Hyprland animations/blur/shadows, and enables Noctalia do-not-disturb. Everything is restored automatically once the game workspace is empty again.
